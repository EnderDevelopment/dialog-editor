# Dialog Editor

Create and manage custom dialogs in Minecraft with ease

## Features

- Create and manage custom dialogs
- Save and load dialogs from JSON files
- Edit dialogs with a user-friendly interface

## Requirements

- Minecraft Java 1.21.4+
- Fabric Loader 0.15.11+
- Fabric API 0.99.11+

## Installation

1. Download the latest release from the [Releases](https://github.com/EnderDevelopment/dialog-editor/releases) page.
2. Place the downloaded JAR file in your Minecraft `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

### Commands

- `/dialog` - Open the dialog editor

### Permissions

- Non-OP players can use the `/dialog` command to create and manage custom dialogs.

## Configuration

Dialogs are saved as JSON files in the `dialogs` folder within your Minecraft directory. You can manually edit these files to customize your dialogs.
